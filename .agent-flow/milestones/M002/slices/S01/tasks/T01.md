Implement two helpers:

- `parseAuthorizationHeader(header)` returns `{ ok: true, token }` or `{ ok: false, error }`
- `requireBearerToken(header)` returns the token or throws a stable error

This task is intentionally chosen for V1 testing because it exercises:

- worker execution on a real code change
- shared proxy credential forwarding during a real LLM run
- review / self-review on auth logic
- reducers on noisy test output if a regression is introduced on purpose during the protocol
